# Shyan Hafeez Khan — Engineering Project Portfolio

A single-page website showcasing my mechanical and automotive engineering projects, with a focus on automotive and high-performance engineering. It presents six featured design, simulation and build projects and is built to be shared freely with employers.

**Live site:** hosted on GitHub Pages.

## About

I'm an MSc Automotive Engineering student at Cranfield University, following a BEng in Mechanical Engineering at Lancaster. This site brings together the projects I'm most proud of, each with its design imagery, a short overview and the detail behind my contribution.

## Features

- Six featured projects, each with an overview, key points and an image gallery
- Click-to-enlarge lightbox on every image
- Downloadable project portfolio (PDF)
- Contact by email and LinkedIn
- Responsive layout with a mobile menu
- Dark "techy" theme with a Petronas-teal accent

## Built with

Plain HTML, CSS and JavaScript, with no frameworks or build step. The whole site is self-contained, so it runs from any static host.

## Structure

```
index.html                          The whole page (markup, styles and script)
assets/
  Shyan-Khan-Project-Portfolio.pdf  Downloadable portfolio deck
  projects/                         Project images
```

## Viewing locally

Download the repository and open `index.html` in any web browser. No server or installation is required.
